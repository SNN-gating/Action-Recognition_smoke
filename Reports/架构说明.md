# 动作识别：SNN + 时序通道门控架构

## 1. 总体介绍

输入是事件相机的异步事件流 `e_i=(x_i,y_i,t_i,p_i)`，输出是 5 类手势。
本 smoke 把每段约 2 s 的事件流转成 8 个等时双极性（亮度增加事件+亮度减小事件）事件帧，但网络内部保留跨时间步膜电位，并用替代梯度训练 LIF 神经元。

模型有两个可比版本：

- `baseline`：门固定为 1，等价于所有通道始终通过；
- `gated`：每个时间步根据当前事件密度和上一时刻第一层通道脉冲率，产生 16 维软门（“软”指非强制取0或取1，可取0—1间的任意值）。

## 2. 数据处理路线（详见数学建模.word）

events──双极性──> X:[B,8,2,32,32]
                              │
                              |逐时间步 t=1...8
                              ▼ 
                    卷积(2→16,s=2)+组归一化+LIF ──> S1_t
                              │
       [mean(X_t), channel_mean(S1_{t-1})] ──> sigmoid gate（软门） G_t
                              │
                              └── S1_t ⊙ G_t
                                      │
                         Conv(16→24,s=2)+GN+LIF
                                      │
                         Conv(24→32,s=2)+GN+LIF
                                      │
                           GlobalAvgPool + Linear(5)
                                      │
                         8 个时间步 logits 取均值

总参数量为 11,253。输入尺寸固定为 `B×8×2×32×32`，输出为 `B×5`。

## 3. 训练伪代码

input: raw DVS events, 200-Hz string annotations
output: best checkpoint selected only by validation accuracy

for each session:
    segments = contiguous_non_none_runs(annotation)
    assert 5 classes × 5 repetitions
    for segment in segments:
        X = temporal_bin(events_in_segment, T=8, polarity=2, H=W=32)
        X = log1p(X) / max(log1p(X))

split:
    train = subject03/05/10, repetition 1..4 # 60
    val   = subject03/05/10, repetition 5    # 15
    test  = subject07, repetition 1..5       # 25, untouched during selection

for model in [baseline, gated]:
    reset seed to 20260813
    initialize Conv-GN-LIF network
    for epoch in 1..80:
        for (X, y) in shuffled_train_batches:
            reset all membrane states at batch entry
            logits_t = []
            previous_S1 = zeros
            for t in 1..8:
                S1, U1 = LIF(stem(X[t]), U1)
                G = ones if baseline else sigmoid(gate_features(X[t], previous_S1))
                S2, U2 = LIF(conv2(S1 * G), U2)
                S3, U3 = LIF(conv3(S2), U3)
                logits_t.append(linear(global_average_pool(S3)))
                previous_S1 = S1
            loss = CE(mean(logits_t), y) + gate_penalty
            backward_with_surrogate_gradient(loss)
            clip_gradient_norm(1.0)
            AdamW_step()
        evaluate_on_validation()
        keep_first_checkpoint_with_highest_validation_accuracy()
    evaluate_best_checkpoint_once_on_subject07_test()
